# Version 0.8

## Interface and lyrics
- Shared checkbox visuals and AppDropdown surfaces, including translation/image pickers and lyric display options.
- Centered settings dialog available from both player and Studio, grouped by appearance, lyrics, playback, online services and storage.
- Word highlighting and performer alignment switches affect main, sidebar and Studio preview without changing recorded times.
- Translation size, font weight, width, letter spacing and italic controls.
- Recently played library table with timestamps and sorting; returning to the library reveals the playing song.
- Studio volume uses the same player volume.
- Sustained words use a media-time glow envelope; larger interlude dots fill in three equal timed segments.

## AMLL
Search priority: Spotify ISRC, Spotify ID, exact title/artist (album used for disambiguation). Multiple entries are treated as revisions only if linked by a shared recording identifier. Missing results preserve local lyrics. Terminal notices disappear after three seconds, with one shared timer across lyric views. Searching/downloading remain visible until complete.

## Native Windows audio
The separate mpv helper uses WASAPI and genuine audio-exclusive mode. The original browser output remains available. Switching keeps the shared media clock; failed device changes restore the previous song position and output. ReplayGain is applied in the active backend only. Helpers are started hidden and accept a restricted command set; local audio bytes never become renderer-supplied file paths or remote URLs.

The bundled Windows x64 helper is in desktop/native. Its README contains the exact official build, checksum and source provenance. Include corresponding source and dependency notices before distributing a packaged release. No application EXE was built for this update.
